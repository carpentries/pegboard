# Add a pegboard node before or after a node

These nodes have the namespace of "http://carpentries.org/pegboard/"

## Usage

``` r
add_pegboard_nodes(node, df)
```

## Arguments

- node:

  a single node

- df:

  a data frame generated from
  [`make_div_pairs()`](https://carpentries.github.io/pegboard/reference/make_div_pairs.md)

## Value

NULL, invisibly
