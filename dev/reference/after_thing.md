# Check if a node is after another node

Check if a node is after another node

## Usage

``` r
after_thing(body, thing = "code_block")
```

## Arguments

- body:

  an XML node

- thing:

  the name of the XML node for the node to be after, defaults to
  "code_block"

## Value

a single boolean value indicating if the node has a single sibling that
is a code block
